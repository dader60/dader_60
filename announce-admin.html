⚙️ 上傳到網站的設定（只存在這台裝置的瀏覽器）
到 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。Repository access 選「Only select repositories」並勾這個網站的儲存庫；Permissions → Repository permissions → Contents 設為 Read and write。權杖只存在你這台裝置，不會寫進網頁，也不會傳給其他人。
時間以你目前裝置的時區為準。可以先發布、設定未來的開始時間，時間一到網站就會自動顯示；過了結束時間會自動收起來。
